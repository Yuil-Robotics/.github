# Yuil-Robotics 공통 GitHub 설정

조직의 모든 저장소에 적용되는 기본 community health files입니다.

- `.github/ISSUE_TEMPLATE/`: 이슈 템플릿 (버그 리포트, 기능 요청). 반드시 이 경로에 둬야 적용됩니다. 템플릿에 쓴 라벨은 이 저장소와 사용하는 저장소 양쪽에 있어야 합니다.
- `pull_request_template.md`: PR 템플릿

자기 파일이 없는 저장소에 자동으로 적용되고, 여기서 수정하면 바로 반영됩니다. 저장소에 같은 종류의 파일이 있으면 그 저장소에는 이 기본값이 적용되지 않습니다 (합쳐지지 않음).

이 저장소는 public입니다. 내부 정보는 넣지 마세요.
